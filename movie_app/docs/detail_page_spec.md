# 详情页功能清单（各端）

本文档以 **`AndroidIntroDesignV3Page`**（`lib/pages/design_reference/android_intro_design_v3_page.dart`）为 **UI 与信息架构基准**，约定正式 **`DetailPage`**（`/detail`）在各端应对齐的能力范围。

## 明确不包含

- **评论 / 短评 / 本地影评**：产品内不提供；详情与统计页不展示相关入口或数据。
- **应用内仿系统状态栏**（假时间、假信号、假电量等）：不在设计基准页与正式详情中绘制；状态栏由系统负责。

## 端划分

| 端 | 布局 |
|----|------|
| Android / iOS | 单列：播放器 + 下方滚动信息区（`DetailMovieInfoSection`） |
| Web（窄屏） | 同单列结构；播放能力受平台与依赖限制，单独验收 |
| Web（宽屏） | 与 Windows 宽屏相同分栏：左播放器 + 左下信息（`DetailDesktopLeftSection`）；右栏**顶部**为「选集 / 播放线路」Tab，其下为「磁力 / 推荐」Tab（`DetailDesktopRightSidebar`）。条件为宽度 ≥ 断点（见 `detail_page.dart`） |
| Windows（宽屏） | 同上；条件为桌面 OS 且宽度 ≥ 断点 |
| Linux / macOS（桌面） | 与 Web / Windows 同构：宽度 ≥ 断点时走宽屏分栏（`DetailPage` 中 `useWideDetailSplit` 含三桌面平台）。 |

> 与 `docs/features_by_platform.md` 第二节一致；宽屏分栏覆盖 **Windows / Linux / macOS**。

## 功能清单（按基准模块）

### 1. 播放器区域

| 项 | 说明 |
|----|------|
| 16:9 播放区 | 宽度驱动高度，与基准一致 |
| 播放/暂停 | 绑定真实播放状态 |
| 进度与拖拽 | 与播放进度一致 |
| 时间展示 | 当前/总时长 |
| 缓冲提示 | 有数据时展示，无则隐藏或降级 |
| 倍速 | 与播放器倍速 API 一致 |
| 音量 | 系统或应用内策略（按端） |
| 投屏 | 按端能力（如 DLNA） |
| 全屏 | 按端（含桌面窗口全屏） |
| 返回 | 系统返回或顶栏返回 |

### 2. 标题与元信息

| 项 | 说明 |
|----|------|
| 主标题 | 来自 `Movie.name` |
| 评分展示 | 与数据源约定（站点分等）；无数据时降级，不强制「豆瓣」文案 |
| 年/类型/时长等摘要 | 与基准「元信息行」同级展示 |

### 3. 简介

| 项 | 说明 |
|----|------|
| 「简介」标题 | 与基准一致 |
| 折叠/展开 | 默认收起约两行，可展开全文；无障碍可读 |

### 4. 主操作行

| 项 | 说明 |
|----|------|
| 下载 | 接缓存/下载任务（按端） |
| 收藏 | 接收藏存储与状态 |
| 分享 | 接系统分享 |

### 5. 上 Tab：选集 / 播放线路

| 项 | 说明 |
|----|------|
| Tab 切换 | 「选集」与「播放线路」互斥内容区 |
| 选集 | 展示当前线路分集，当前播放集高亮 |
| 线路 | 切换线路；**切换后集号策略**（保持同集索引或回退）需产品明确 |

### 6. 下 Tab：推荐 / 磁力

| 项 | 说明 |
|----|------|
| Tab 切换 | 「推荐」与「磁力」互斥内容区 |
| 推荐 | 横向卡片或等价展示，数据 `relatedMovies` |
| 磁力 | 列表 + 刷新/打开等，与现有磁力检索能力一致 |

### 7. 验收优先级建议

1. 手机单列：信息区结构与基准对齐（Tab、折叠简介、主操作行）。  
2. Web / Windows 宽屏右栏：「选集 / 播放线路」在右栏**最上方**，「磁力 / 推荐」在其下；与基准 Tab 命名、顺序、视觉对齐。  
3. Web：非播放信息区对齐；播放单独里程碑。

## 修订记录

- 初版：以静态设计为基准；排除评论与仿系统状态栏。
- 宽屏右栏：「选集 / 播放线路」置于右栏最上方 Tab，其下为「磁力 / 推荐」；Web 与 **Windows / Linux / macOS** 桌面在宽度 ≥ 断点时同构分栏。
