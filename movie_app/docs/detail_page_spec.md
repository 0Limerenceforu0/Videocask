# 详情页功能清单（各端）

本文档以 **`AndroidIntroDesignV3Page`**（`lib/pages/design_reference/android_intro_design_v3_page.dart`）为 **UI 与信息架构基准**，约定正式 **`DetailPage`**（`/detail`）在各端应对齐的能力范围。

## 明确不包含

- **评论 / 短评 / 本地影评**：产品内不提供；详情与统计页不展示相关入口或数据。
- **应用内仿系统状态栏**（假时间、假信号、假电量等）：不在设计基准页与正式详情中绘制；状态栏由系统负责。

## 端划分

| 端 | 布局 |
|----|------|
| Android / iOS | 单列：播放器 + 下方滚动信息区（`DetailMovieInfoSection`） |
| Web（窄屏） | 同单列结构；播放能力受平台与依赖限制，单独验收 |
| Web（宽屏） | 与 Windows 宽屏相同分栏：左播放器 + 左下信息（`DetailDesktopLeftSection`）；右栏**顶部**为「选集 / 播放线路」Tab，其下为「磁力 / 推荐」Tab（`DetailDesktopRightSidebar`）。条件为宽度 ≥ 断点（见 `detail_page.dart`） |
| Windows（宽屏） | 同上；条件为桌面 OS 且宽度 ≥ 断点 |
| Linux / macOS（桌面） | 与 Web / Windows 同构：宽度 ≥ 断点时走宽屏分栏（`DetailPage` 中 `useWideDetailSplit` 含三桌面平台）。 |

> 与 `docs/features_by_platform.md` 第二节一致；宽屏分栏覆盖 **Windows / Linux / macOS**。

## 功能清单（按基准模块）

### 1. 播放器区域

| 项 | 说明 |
|----|------|
| 播放区比例 | 横屏片源默认 16:9；竖屏片源按真实比例；**Android 非全屏竖屏片源播放器槽高为屏幕高度 50%** |
| 播放/暂停 | 绑定真实播放状态 |
| 进度与拖拽 | 拖动中快速 Seek（`hr-seek`），松手精确 Seek |
| 时间展示 | 当前/总时长 |
| 缓冲提示 | 有数据时展示；长时间缓冲可自动换线（受播放策略影响） |
| 倍速 | 与播放器倍速 API 一致 |
| 音量 | 系统或应用内策略（按端）；右半屏竖滑调音量 |
| 亮度 | 左半屏竖滑调亮度（移动端） |
| 投屏 | 按端能力（如 DLNA） |
| 全屏 | 移动端沉浸全屏；桌面为窗口全屏（`window_manager`） |
| 全屏方向（移动） | 非全屏仅竖正/竖倒；全屏时横屏片源允许四向（竖正、竖倒、左横、右横），竖屏片源仍仅竖屏；逻辑见 `DetailVideoLayout.preferredOrientations` |
| 锁屏（移动） | 仅 Android / iOS；Android 全屏时左右各一锁钮，iOS 左侧；Windows / 桌面无锁屏 |
| 返回 | 系统返回或顶栏返回 |

**播放链路（与设置联动，非 Web）**

| 项 | 说明 |
|----|------|
| 解析顺序 | 本地已完成缓存 > `VideoParser` 解析页 > 原始 URL |
| 智能选线 | 按播放策略对线路 Range 探针评分（`PlaybackRouteSelector`） |
| 预加载下一集 | 播至约 80% 时解析下一集 URL（可关） |
| 播放预缓冲 | 任意网络下 Range 预拉下一集前几 MB（可关；设置项「播放预缓冲」） |
| 播放策略 | 流畅 / 均衡 / 画质，映射 mpv 缓冲、Seek、`cache-secs`、换线阈值等 |

### 2. 标题与元信息

| 项 | 说明 |
|----|------|
| 主标题 | 来自 `Movie.name` |
| 评分展示 | 与数据源约定（站点分等）；无数据时降级，不强制「豆瓣」文案 |
| 年/类型/时长等摘要 | 与基准「元信息行」同级展示 |

### 3. 简介

| 项 | 说明 |
|----|------|
| 「简介」标题 | 与基准一致 |
| 折叠/展开 | 默认收起约两行，可展开全文；无障碍可读 |

### 4. 主操作行

| 项 | 说明 |
|----|------|
| 下载 | 接缓存/下载任务（按端） |
| 收藏 | 接收藏存储与状态 |
| 分享 | 接系统分享 |

### 5. 上 Tab：选集 / 播放线路

| 项 | 说明 |
|----|------|
| Tab 切换 | 「选集」与「播放线路」互斥内容区 |
| 选集 | 展示当前线路分集，当前播放集高亮 |
| 线路 | 切换至**其他**线路时重新加载；**点击当前线路不重新加载** |
| 换线集号 | **保持当前集索引**（按新线路集数上限截断）；播放器内「线路 / 清晰度」弹层同此策略 |

### 6. 下 Tab：推荐 / 磁力

| 项 | 说明 |
|----|------|
| Tab 切换 | 「推荐」与「磁力」互斥内容区 |
| 推荐 | 横向卡片或等价展示，数据 `relatedMovies` |
| 磁力 | 列表 + 刷新/打开等，与现有磁力检索能力一致；中文片名搜索可经 IMDb `tt` 号聚合检索 |

### 7. 磁力详情入口（补充）

| 项 | 说明 |
|----|------|
| 路由 | `sourceId` 为磁力详情源时走独立详情流，不覆盖全局 `MovieProvider` CMS 详情 |
| 播放 | 优先路由 `initialMagnetUri`，与 CMS 播放器互斥；准备中禁用 CMS 换线 |

### 8. 验收优先级建议

1. 手机单列：信息区结构与基准对齐（Tab、折叠简介、主操作行）。  
2. Web / Windows 宽屏右栏：「选集 / 播放线路」在右栏**最上方**，「磁力 / 推荐」在其下；与基准 Tab 命名、顺序、视觉对齐。  
3. Web：非播放信息区对齐；播放单独里程碑。

- 2026-05-29：补充播放链路（策略、预缓冲、智能选线）、全屏方向与锁屏规则、线路切换行为、磁力详情入口约定。
